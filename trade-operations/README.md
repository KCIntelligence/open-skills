# 小型贸易商运营技能组

面向中小型贸易企业（可含电商和广告业务）的 15 项经营技能。覆盖采购、库存、供应商、客户交付、结算现金和经营改善一整条闭环。每个技能的第一步都会先列出需要哪些资料、哪些必须、哪些可选，再分析、给决策建议，最后说明怎么检验结果。

## 从哪里开始

- [了解贸易企业任务闭环地图](docs/TRADE-OPERATING-MAP.md)
- 技能目录：按要解决的问题选择技能（见下文"按业务问题选技能"）。
- 首次输入资料指南：没有准备好数据时如何开始（见下文"没准备好数据怎么开始"）。

## 按业务问题选技能


| 你要解决的事                    | 对应技能              |
| ------------------------- | ----------------- |
| 商品该保留还是退出、利润为何变化、广告值不值得继续 | 商品组合、毛利改善、营销盈利    |
| 什么时候缺货、补多少、账上库存是否可信       | 需求库存计划、库存账实核对     |
| 向谁买、已下订单如何到货、供应商反复迟交怎么办   | 寻源选择、采购订单跟进、供应商绩效 |
| 本单能否承诺、能否按期送达、退换货如何恢复     | 订单审核、订单交付、退换货索赔   |
| 哪些往来未结、采购承诺会不会造成现金缺口      | 结算核对、现金计划         |
| 跨领域该优先做什么、行动有没有带来改善       | 经营复盘、改善行动跟踪       |




## 15 项技能一览


| 技能            | 英文名                           | 解决什么                                  |
| ------------- | ----------------------------- | ------------------------------------- |
| 需求预测、库存风险与补货  | trade-demand-inventory-plan   | 按 SKU 和日期识别缺货及积压，比较补货、调拨和停补方案并跟踪库存效果。 |
| 寻源、比价与供应商选择   | trade-supplier-sourcing       | 在规格、到货和成本约束下比较供应商报价，形成可执行的供货选择方案。     |
| 供应商绩效与持续改善    | trade-supplier-performance    | 分开分析供应商迟交、短交和质量问题，形成整改、限用或备选建议并复评。    |
| 采购订单跟进与到货恢复   | trade-purchase-order-followup | 跟踪采购订单剩余合格数量和预计可用日，处理延期、短交与到货异常。      |
| 库存账实与可用状态核对   | trade-stock-accuracy          | 对齐盘点与账面时点，解释 SKU 库存差异，核验可售、冻结与在途状态。   |
| 报价与客户订单承诺审核   | trade-sales-order-review      | 结合价格利润、库存交期和客户信用，审核报价或订单可承诺的具体条件。     |
| 客户订单交付与异常处置   | trade-order-fulfillment       | 把已承诺订单落实到分配、拣货、发运和签收，处理交期与数量异常。       |
| 退换货、质量异常与索赔   | trade-returns-claims          | 核对退换货资格与涉事商品，比较补救方式并跟踪货品处置和赔付结果。      |
| 应收应付核对与逾期处理   | trade-settlement-reconcile    | 按单据核对应收应付、收付款和贷项，识别差异、逾期及下一步处理。       |
| 现金预测与采购承诺安排   | trade-cash-planning           | 按收付时点预测现金缺口，比较采购、付款和催收安排并检验实际偏差。      |
| 商品组合与生命周期经营   | trade-product-portfolio       | 结合销量、贡献、供货和库存，提出商品保留、培育、收缩与退出方案。      |
| 营销投入与获客盈利优化   | trade-marketing-profitability | 核对广告归因和成本，比较活动投入方案并验证增量贡献与库存承接。       |
| 毛利变化诊断与价格成本改善 | trade-margin-improvement      | 拆解销量、价格、成本与组合变化，评估调价、折扣和成本改善的利润影响。    |
| 经营复盘与跨领域决策    | trade-management-review       | 汇总销售、毛利、库存、供应商和现金变化，形成管理层取舍与行动组合。     |
| 改善行动推进与收益验收   | trade-improvement-track       | 按责任、依赖和期限推进已选改善措施，区分动作完成和实际业务收益。      |




## 没准备好数据怎么开始

不用等数据齐全再动手。每个技能的第一步都会先列一张资料清单，把要的东西分成三类：

- 必须：缺了就没法做核心判断的
- 条件必需：只有特定情况才要的
- 可选：有了更准，没有也能先出结论

所以你可以先把手头有的资料直接交给技能，哪怕只有一部分。技能会告诉你：现在已经具备什么、还缺哪些必须的、哪些可以暂时不提供。缺的东西会按轻重排好，不用你自己猜。

资料也不用先整理成固定格式。原始的表格、清单、截图、一段文字都行，技能负责从里面取数和对齐口径。

## 怎么用

- 每个技能独立可用，只装你需要的那一个就行，不必整套都装。
- 相关技能一起用能形成闭环。例如采购订单延期：先用"采购订单跟进"确定剩余合格量和可用日期，再用"需求库存计划"重算缺货，用"订单交付"评估客户影响，用"现金计划"看加急采购会不会造成现金缺口。



## 使用示例

```text
使用 trade-demand-inventory-plan 看未来 30 天哪些 SKU 会缺货。
我先上传库存表和在途采购表，请说明已经具备哪些资料，
还缺哪些必须信息，哪些可以暂时不提供。
```

```text
使用 trade-supplier-performance。
请根据采购承诺、分批收货与质量记录，区分本期迟交、
短交和质量问题，提出供应商整改及复评建议。
```

```text
使用 trade-management-review。
请检查本期增投、补货和现金计划是否相互冲突，
给出需要管理层决定的方案和取舍，不执行外部动作。
```



## 边界

- 默认不涉及生产制造、报关、税务申报、融资交易。
- 安装不授予下单、改价、调账、付款、发送消息或持续监控的权限；分析、动作执行和业务收益分别报告。
