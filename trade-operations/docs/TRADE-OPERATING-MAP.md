# 贸易企业任务闭环地图

[← 返回技能组主页](../README.md)

适用对象：约30–50人的商品贸易企业，承担采购、库存、供应商和客户交付管理，可含电商与广告渠道。

以商品流、订单流、资金流和经营结果组织工作，不按部门或软件划分技能。

生产制造、报关、税务申报、融资交易不默认纳入；存在这些业务时另行定义范围。

## 业务主线与经营控制

```text
商品组合与销售机会
  ├─营销投入与利润诊断 ──影响需求、价格和商品选择
  ├─需求与库存计划 ──寻源选择 ──采购订单跟进 ──验收入库
  └─客户订单审核 ──库存分配与发运 ──客户签收 ──应收结算
                         ↑                │
                    库存准确性        退换货与索赔
采购、发票和收货 ──应付核对 ──付款安排 ──现金计划
                         ↓
经营复盘：汇总销售、利润、服务、库存、现金之间的取舍
改善跟踪：推进已选行动，验证实际业务效果，反馈原业务闭环
```

此图表示业务关系，不代表所有任务都运行所有技能。

## 结果归属与验收


| 业务任务     | 唯一主决策／结果              | 主要交付物             | 结果检验               | Skill                           |
| -------- | --------------------- | ----------------- | ------------------ | ------------------------------- |
| 商品与品类经营  | 哪些商品保留、培育、收缩或退出       | SKU组合建议与退出影响清单    | 同口径贡献、周转、服务和库存退出效果 | `trade-product-portfolio`       |
| 营销投入优化   | 哪些活动增投、限投、暂停或试验       | 活动级预算调整方案         | 同归因窗口的增量贡献与获客效果    | `trade-marketing-profitability` |
| 毛利与价格改善  | 利润为什么变，哪些价格／折扣／成本措施有效 | 利润差异桥与措施测算        | 可比收入、毛利额、毛利率及销量约束  | `trade-margin-improvement`      |
| 需求与库存计划  | SKU何时、补多少、是否应停补或调拨    | 缺货时间表、补货及积压处理建议   | 供货覆盖恢复且积压／资金约束未恶化  | `trade-demand-inventory-plan`   |
| 寻源与供应商选择 | 向谁采购、以何种供货组合满足需求      | 同口径比价、资格缺口、推荐授标方案 | 获批供应方案；首单效果另作验证    | `trade-supplier-sourcing`       |
| 供应商绩效改善  | 哪些供应商需整改、限用或发展备选      | 交期／数量／质量分项评价与整改计划 | 后续到期订单的持续表现        | `trade-supplier-performance`    |
| 采购订单履行   | 既有PO的剩余合格数量何时可用       | PO行级催交、分批、替代方案    | 实际合格收货与剩余义务        | `trade-purchase-order-followup` |
| 库存准确性    | 同一时点的实物、账面、可用状态是否一致   | 差异原因、复盘点建议、调整申请   | 复盘点及获批调整后的账实核对     | `trade-stock-accuracy`          |
| 客户订单审核   | 本次订单能否按价格、信用和交期承诺     | 接单／拆单／改期／拒单建议     | 条件确认并可交付接续         | `trade-sales-order-review`      |
| 客户订单交付   | 已承诺订单是否足量、按时、完好送达     | 订单行交付计划与异常处置单     | 签收、数量、质量及单证        | `trade-order-fulfillment`       |
| 退换货与索赔   | 客户补救和涉事货品处置是否完成       | 退货处置、赔付／追偿建议      | 补救兑现与库存、结算变动分别核验   | `trade-returns-claims`          |
| 往来结算核对   | 哪些应收应付有效、已结、争议或逾期     | 单据匹配、余额、差异和催收清单   | 财务确认及实际收付款核销       | `trade-settlement-reconcile`    |
| 现金计划     | 到期收支下何时缺钱、如何安排可选支出    | 逐期现金表与采购承诺压力方案    | 实际现金余额与预测偏差        | `trade-cash-planning`           |
| 经营复盘与决策  | 跨领域风险优先级及管理层取舍        | 经营简报、决策议题和行动组合    | 后续经营指标及已选行动结果      | `trade-management-review`       |
| 改善行动跟踪   | 已选行动是否兑现预期收益          | 依赖计划、进展、验收与效果复盘   | 区分动作完成和业务收益实现      | `trade-improvement-track`       |


商品／营销／利润／库存／采购／供应商／现金／经营复盘来自目标需求的明确问题。客户订单审核、交付、库存账实、退货、结算、寻源是为形成贸易端到端闭环补充的业务环节，不是假定企业一定已有相应制度或数据。

## 每个技能的决策和结果责任说明

决策与结果责任是核心，数据或分析技术是手段。每一个主技能，都都一个责任角色、一个验收口径；同一SKU、PO、销售订单可以被多个技能读取。

- **计划 vs 采购执行**：计划决定补货需求与时间；采购跟进负责已有PO能否兑现，不重复创建采购数量。
- **单笔延期 vs 供应商改善**：前者解决当前缺货；后者解决跨订单的重复失约，不以一次催单代替持续改善。
- **商品 vs 毛利 vs 营销**：商品技能拥有组合／生命周期决策，毛利技能拥有价格／成本诊断，营销技能拥有活动预算决策。共同使用贡献数据但不重复认领同一收益。
- **实物 vs 结算 vs 现金**：合格入库、应付成立、款项支付是不同事件；货已退不等于退款已到账。
- **经营复盘 vs 改善跟踪**：前者选择跨领域优先级，后者推进已选择事项；不替业务技能重新编造业务判断。

各技能可独立完成自身任务；相关技能未安装时输出可交接的表格，不因缺少“编排器”而拒绝工作。
