# 分组管理对比

帮助分组负责人判断：本组哪些对象需要关注，差距是集中在少数对象还是出现在多个对象，哪些事项值得一起核查或协调。分组是已有的业务归属，不是让Agent重新划分客户、供应商或项目类别。

本技能处理指定分组在一次活动、阶段或其他区间的表现；不扩展成所有分组的自动优劣评定。

## 先锁定本组和这次要看的问题

资料不足时，简短引导：“把这次结果发给我，告诉我要看哪个组、准备给谁看。我会整理组内差距和需要一起核查的事项。”

从已有资料确认当期对象归属、评价结果、原始缺项及可用基准。已有信息不重复询问，不要求专门的输入配置表。历史归属按当时有效关系处理，不拿当前分组覆盖过去。

只展示获准的本组对象及字段。其他组仅在有授权时使用聚合基准；有权看到平均值，不等于有权披露形成平均值的对象名单、极值身份或源记录。

## 分清人数、表现和组内差异

核对本组应有对象、综合参评对象、未参评与待定对象，以及各指标原始有效数。不要因为某对象缺项而从本组名单中消失。

使用既有评价结果，不重新加权生成另一套总分。本组均值、中位数与各项基准说明比较池及样本数；原始缺失不计0，估算值不冒充实际表现。

| 要做的比较 | 判断与处理 |
| --- | --- |
| 本组内部对象对比 | 保留正式全范围名次；若另列组内位置，标清组内参评数并沿用适用并列口径，不改写正式名次 |
| 本组与组织基准比较 | 核对业务区间、指标定义、计分方式及样本资格一致，说明基准是否包含本组 |
| 分组整体表现 | 按确认口径汇总；没有业务加权规则时，可报告明确标注的对象等权均值，但不冒称正式分组考核分 |
| 分组规模不同 | 同时说明人数和覆盖情况；不累加对象总分后按总量判优劣，不将各组均值等权平均为组织对象均值 |
| 比率、数量等不同类型指标 | 比率按适用分子分母重算，量尺不同的维度分别解释，不用原始数值大小比较重要性 |

没有适用基准时，先展示组内已知分布和缺口，不臆造组织平均。样本少、对象业务不同或覆盖偏斜时，将限制写在差距旁，避免把样本差异说成管理差异。

## 找出可以共同核查的事项

先把同一对象的多项差距归在一起，再检查是否多个对象在同一维度出现相似信号。说明对象数量、比较标准及覆盖情况，不把缺失项计入“表现较差”的数量。

共同弱项只是核查线索，不证明共同根因。结合实际记录判断是否需要跨对象协调：例如统一解释口径、汇总相似扣分明细、核对共用环节。没有这些依据时，建议止于取得记录，不直接安排培训、资源重配或问责。

排序关注项时结合已知差距与有证据的业务影响，不把差距最大等同于损失最大。原始指标越低越好时，差值为正可能表示更差，不能机械写成提升。

## 把比较转成可交接的核查事项

每项关注点说明涉及对象、指标差距、事实来源、已有措施、尚待核实内容、建议协同岗位，以及下一次用什么数据复核。已有措施和完成状态只引用实际台账；没有台账不写“整改未完成”。

历史比较要核对对象归属、范围、规则和指标含义。成员更换时，不把组均值变化直接归因为同一批对象进步；两次可比记录只说明前后变化，不写长期趋势。

## 交付给分组负责人

简报先说明本组范围和数据覆盖，再呈现对象差距，最后列共同关注项和协调建议。主体可用约两页，超出明细放附件，按用户模板和阅读习惯调整。

按任务交付文档、同版PDF、横版图卡及本组明细表。对象×指标矩阵或差距图使用一致量尺，缺项明确写“缺”，不画成0分。附图表数据、基准口径与来源，文档和图卡不得额外携带其他组对象明细。

交付前核对本组名单、正式名次、基准分母及全部输出的可见范围；检查文件数值和版面。指定格式无法生成时说明限制，不冒称完成。

结尾指出组内哪些事实可用、哪些事项需负责人组织核查。到此结束，不重划分组、不下达未经确认的任务、不自动发送简报。
