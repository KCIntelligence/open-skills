# 单对象表现诊断

帮助对象负责人看清自己与适用基准差在哪里、哪些信息还不够，以及下一步先核查什么。这里的诊断针对已有表现和证据，不凭几项分数解释事故、能力或经营损失。

一次处理指定对象在某个活动、阶段或其他业务区间的表现。对象可以是项目、门店、供应商等，不因对象类别改变就另建一套行业诊断系统。

## 从对象和关注点开始

资料不足时，简短引导：“把这个对象的评价结果发给我，告诉我想重点看什么。我会对照已有基准找出差距，有具体问题记录也可以一起提供。”

从现有资料确认对象身份、业务区间、数据版本、指标含义及可见范围。原始成绩、综合计分值、展示估算和正式结果分别读取；不要求用户先制作技术数据包。

使用已有总分、资格和名次，不在诊断时生成另一套排名。对象未参评或资格待定时标明原因，正式总分和名次留空；已有有效单项仍可分析，不用展示补值补出完整表现。

## 选择真正可比的基准

优先使用任务中已确认的基准，核对业务范围、指标定义、计分方式、样本资格和时间区间。区分比较的是实际原分、封顶后的综合计分值，还是另一种业务指标；原分不能与封顶均值直接相减。

明确基准来自哪个范围、包含多少对象以及是否包括被诊断对象。只有获准的聚合值时，可使用聚合值，不要求或透露其他对象明细。没有适用基准时先描述已有表现和证据缺口，不自行选一个有利或不利的对照对象。

不同量尺分别解释；对越低越好的指标，数值差为正可能表示较差。未掌握方向、单位或分母时，不先写“领先”“落后”。

## 把表现差距和原因解释分开

| 现有证据 | 可以做什么 | 不能据此推出什么 |
| --- | --- | --- |
| 原始成绩与同口径基准 | 计算分差，定位应关注的维度 | 具体扣分事件或责任原因 |
| 原始缺项或展示估算 | 说明资料缺口及对结论的影响 | 实际表现为0或达到估算水平 |
| 可定位到对象、时间和指标的问题记录 | 描述已记录事件及其与评价的关系，标明尚未证实的关联 | 将单个事件解释为全部差距的来源 |
| 已实施措施记录 | 陈述做过什么、何时实施 | 措施已经有效、问题已经关闭 |
| 同口径的后续复核证据 | 描述复核结果及支持范围 | 排除其他因素后认定唯一因果 |

原始分差为“对象原分−基准原分”，保留单位和方向。需要解释综合分差时，可按既定权重分解各项计分值的差距；使用同一比较池、相同计分变换，不把“原始均值封顶”当作“逐对象封顶后均值”。分数贡献只解释评价分差，不是损失金额或改善收益。

历史比较先核对对象身份、指标、规则和范围；名次变化还依赖参评池。缺少可比历史就不补写变化。两次记录只说明前后差异，即使记录更多，也需证据支持才能称为持续改善。

## 选择少量有用的核查事项

结合有依据的差距和已确认业务影响选择关注点，通常一到两项足够。差距最大不必然最紧急，已确认的严重事件可能更值得优先核查；没有影响记录时不虚构严重性排序。

每项写清：哪个维度、事实证据、尚缺什么、建议查哪份记录或哪个环节、适合哪个岗位确认、下次看什么数据。只有分数时，可以建议索取扣分明细、核对对象和统计口径；不要直接写换供应商、培训团队或追加预算。

已批准整改记录中的责任人和期限可以转写。没有批准记录时用“建议由相关岗位核实”，不将建议变成正式指令。记录未提供与记录证明未完成是两种情况。

## 交付一张能用于沟通的诊断卡

卡片围绕三部分组织：对象与评价状态；各项原值、适用计分值、基准及差距；优先核查事项与限制。保留正式名次的参评人数，估算值显著标注，不用颜色代替数据状态。

按用户需要交付可编辑文档、单页PDF或竖版图卡。内容较多时将明细放附件，不缩小文字硬塞一页。需要图时用逐维点图或条形比较，保留单位与一致量尺；缺项不画成正常数值，不靠雷达面积判断优劣。

保留计算依据和图表数据，核对对象值与原评价结果一致、基准可追溯，各格式没有额外暴露其他对象明细。实际生成文件后检查数字、分页和裁切，未完成格式明确说明。

将诊断卡交给对象负责人核对事实，将资料问题交给相应岗位。结尾说明当前能支持什么判断以及下一步需要补充什么，到此结束，不实施处置或自动发出整改通知。
