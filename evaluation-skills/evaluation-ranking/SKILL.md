# 评价与排名

让评价经办人和专业负责人能够核对：谁进入了这次评价，分数怎么算出来，同分如何排列，哪些对象暂时不能参评。排名提供统一的比较依据，不自动形成获奖、处罚或业务好坏的最终决定。

评价范围可以是一次活动、一个项目阶段或任意业务区间，不要求按月。对象、指标、权重和门槛来自本次任务，不内置某个行业的制度。

## 从用户已有的表和规则开始

资料尚未提供时，简短引导：“把整理好的数据和这次使用的评价办法发给我，我会核对得分和排名，规则不清楚的地方再具体问你。”

直接读取现有表格和规则说明，不要求用户改成固定JSON，也不要求先运行本系列其他技能。从材料中确定对象范围、业务时间、数据版本和规则适用范围。核对原始值、估算值、缺项和冲突是否分开；未解决的数据问题只阻断受影响的计算。

弄清分数代表什么。原始评分、已经乘过权重的贡献分，以及金额、次数、完成率不是一回事。原始业务指标只有在已有计分办法时才能转成评价分；不自行设计归一化公式或默认等权。

## 先判资格，再计算分数

分别检查综合评价与单项评价的参评条件。综合缺项不必然意味着所有单项都不能参评，具体按适用规则执行。

| 遇到的情况 | 处理 |
| --- | --- |
| 有效原始值为0 | 计为有效观测；不要当成未提交 |
| 原值缺失，只有展示补值 | 原始完整性仍为缺失，不因补值增加参评资格 |
| 综合缺项 | 按已确认规则排除、保留待定或计算；不自行补0、重分权重 |
| 同一对象存在冲突值或版本不一致 | 保留问题与受影响项目，不悄悄挑选有利值 |
| 资格或计分规则尚未确定 | 交付已核实数据和可复算草稿，明确待定项，不给出正式评价结论 |

对未参评、资格待定和参评对象分别保留名单与原因，核对三类合计与本次范围一致；不要把未参评对象塞到榜尾并赋0分。

## 保留每一层计算含义

按已有规则记录原始分、计分转换、封顶后的计分值、权重贡献及总分。只有规则要求封顶才封顶，封顶不等于标准化。单项排名使用原始分或规则明确指定的单项口径，不能顺手沿用综合计分的封顶值。

若规则采用加权求和，总分为各项“权重×计分值”之和。检查权重单位、合计及缺项政策一致；已经加权的贡献分按其定义处理，不重复乘权重。指标有正向、逆向或不同量尺时，按确认的计分与排序方向执行，不把所有数都理解成越大越好。

使用可复算的公式或代码保留计算精度。原精度值、排名比较值和展示值分开：显示成相同的两位小数，不一定表示按正式比较精度同分。

## 把排序规则说清楚

明确比较池、排序方向、比较精度、舍入方式和并列规则。同分可以按既定办法跳号或连续编号，但不能以姓名、代码或文件行序暗中分胜负。展示排序需要次序时，保留同名次并说明只是显示顺序。

需要标记前几位或后几位时，按已确认的并列边界处理，说明实际纳入人数。名次靠后不等于未达标，达标线与奖项条件应当另有规则，本技能不自行决定获奖者。

比较两次结果前，检查对象身份、指标含义、评分规则和参评池是否可比。参评范围或规则改变时，可展示各次原结果及差异背景，不给出未经校准的正式名次升降；没有历史数据就不补写趋势。

## 交付可供核验的评价结果

按用户习惯交付工作簿或数据表，通常包括综合排名、各项排名、未参评及待定对象、计算明细和规则说明；有可比历史时再加入变化。保留对象、业务区间、数据与规则版本、原始状态、资格原因、计分值、比较值及名次。

向后续简报和诊断交付同一组结果，并附指标口径、比较池、样本数和来源定位。已有事实编号则沿用，没有编号时用稳定的表名、字段和记录标识定位，不强制特定事实包格式。

交付前实际复核若干总分及全部资格、并列边界，核对综合与单项使用的值没有混淆。生成工作簿后重读公式与数值，不能只确认文件存在。无法完成指定格式时说明已完成和未完成部分。

结尾说明结果文件、正式或待定范围，以及需要数据提供方或规则负责人确认的具体问题。到此结束，不根据排名安排整改，不外发原始数据或替用户作制度决定。
