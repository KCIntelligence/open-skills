# 对象诊断：解释分差，保留原因的不确定性

以下为合成任务。负责人要求查看对象C在一次项目阶段评价中的差距，获准使用本对象明细和组织聚合基准。

C交付原分80、质量原分100。综合规则已确认：每项上限100，交付权重60%、质量40%，均越高越好。C综合88，正式名次3/3，原始资料完整。

同一比较池3个参评对象、包含C；获准基准为交付原分均值290/3≈96.67，交付计分值均值280/3≈93.33，质量原分及计分值均值260/3≈86.67，综合均值272/3≈90.67。没有扣分明细、历史记录或整改台账。

## 卡片中的表现差距

| 指标 | C原分 | 基准原分均值 | 原分差 |
| --- | ---: | ---: | ---: |
| 交付 | 80 | 96.67 | −16.67 |
| 质量 | 100 | 86.67 | ＋13.33 |

C总分比基准低约2.67，不代表各项都差。若负责人需要理解综合分差，可按同一计分口径解释：

- 交付项使C低于基准：(280/3−80)×60%＝8分。
- 质量项抵消部分差距：(260/3−100)×40%＝−16/3分，约−5.33分。
- 合计基准减C为8/3分，约2.67分；计算保留原精度，最后再展示两位。

不能用交付原分均值96.67直接代替计分值均值93.33，否则会改变总分差的解释。更不能把8分写成经营损失或改善后必然获得的收益。
